# BI-contest - Spending Behavior Analysis & Customer Segmentation

## Overview
Analyzed 1.85M transactions from 999 customers across 693 merchants and 34 provinces.

## Key findings
- Spending rose 179.89% (Feb–Dec), driven by transaction volume (+187.33%).
- Financial health drivers: expense-to-income ratio (r = -0.90), credit utilization (r = -0.86).
- K-Means (k=4, silhouette 0.312) + rule-based 2x2 check; "Danger Zone" = 59 customers (5.91%).
- 6 non-punitive support actions proposed.
